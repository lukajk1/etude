# Instrument sample credits

These recordings power the **Recorded** sound source (`src/audio/sources/samples.ts`).
Each file was trimmed to a few seconds, faded out, leveled, and converted to Ogg Vorbis.
`manifest.json` lists each file and the MIDI note it was recorded at.

## VSCO 2 Community Edition (strings, woodwinds, brass, harp)

By Versilian Studios / Sam Gossner, from <https://github.com/sgossner/VSCO-2-CE>.
Released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/): no rights
reserved, no attribution required (credited here anyway, with thanks).

| Timbre | Recordings used |
|---|---|
| Strings | Solo contrabass (sustain, vibrato), cello section, viola section, violin section (sustain, vibrato) |
| Woodwinds | Bassoon (sustain), clarinet (long sustain), flute (sustain, vibrato) |
| Brass | Tuba, tenor trombone, French horn, trumpet (sustain) |
| Harp | Harp (mf, with f where mf is missing) |

Each timbre combines instruments by register: low notes use the lowest instrument, and
so on up.

## Salamander Grand Piano (piano)

By Alexander Holm, licensed under
[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). These are the MP3 renditions
Tone.js hosts at <https://tonejs.github.io/audio/salamander/>, one sample every minor
third from A0 to C8.
